# Unplugged AFK 0.1.0-alpha.3

- Renames the player marker to `[UNPLUGGED]` to distinguish disconnected representatives from ordinary AFK players.
- Adds optional FTB Ranks permissions for use, administration, automatic logout, duration limits, and limit bypasses.
- Adds UUID allowlist and denylist access modes for servers without a permissions mod.
- Adds configurable maximum durations and simultaneous unplugged-player limits.
- Adds `/unplug status`, `/unplug cancel`, `/unplug next`, and `/unplug auto on|off`.
- Adds opt-in automatic unplugging with a reconnect delay and safe server-shutdown cancellation.
- Improves admin session inspection with remaining time, location, status, and reason.
- Extends the public API with player-instance checks and remaining-session time.
- Avoids registering the optional `/afk` alias when another mod already owns it.
