# Unplugged AFK 0.1.0-alpha.2+mc26.1.2

- Marks unplugged replacements as `[AFK]` above their head and in the TAB list.
- Adds independent configuration toggles for the AFK nameplate and TAB entry.
- Keeps the replacement in the TAB list after vanilla finishes disconnect cleanup.
- Resolves bundled language text server-side so vanilla clients receive readable messages.
- Broadcasts translated unplugged and returned lifecycle messages by default.
- Migrates legacy message configuration and removes obsolete inline message strings.
- Suppresses synthetic join/leave messages, including the returning player's vanilla join line.
